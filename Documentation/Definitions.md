
# Malware Identification and Definitions


#### **File Infectors**
>`AKA:` Viruses / Parasites
>
>`Description:` Add malicious code into good executibles and alter the  
>                        PE entry point to start with malicious code. 
>
>`Facts:` 
>- More prevalent in Windows XP, less common now and most Antivirus catch them. 
>- Persistence mechanism for spreading malware
>
>`Identifiers:`
>- Alters only executables
>- Does not change file extensions
>- Can compare hash of clean file to identify
