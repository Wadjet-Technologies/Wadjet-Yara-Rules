# Wadjet-Yara-Rules
Yara Rules for detecting Malware or suspicious activity.

Definitions and Detection tips can be found [here](./Documentation/Definitions.md)

Theses Yara rules can be paired with a static malware checker named [Meanie Checker](https://github.com/CharisGrubb/MeanieChecker)


*Currently this is designed for Windows; plan is to add compatability to Linux and MacOS, as well as other options for runners (such as C++ for more efficiency)
